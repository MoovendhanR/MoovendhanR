## 🧠 About Me

**Full-Stack Engineer** with **5+ years of hands-on experience** in JavaScript and TypeScript, currently building fintech products at **FinRight** in Bengaluru.

I've worked across the whole stack of a Provident Fund (EPF/CMPF) services platform and its sister product Thefynprint: **1,600+ commits across 7 production codebases**, covering payments and subscriptions, government-portal automation, an AI claim agent, dashboards, a CMS and a mobile app.

I take features from requirement → API design → UI → tests → deployment on AWS, with a focus on:

- 💳 Payments that clear: subscriptions, webhooks, retries and failure tracking
- 🤖 Browser automation and agentic AI that does real work
- ⚙️ Reliable background jobs and queues
- 🧩 Clean, testable code the next person can change with confidence

🟢 **Open to Full-Stack / Backend roles** in fintech, SaaS or AI-product teams · Bengaluru or remote
